#  YouTube Clone Web Application

Aplikasi web klon YouTube yang interaktif dan responsif, dirancang untuk menampilkan antarmuka pemutar video berbasis web lengkap dengan navigasi kategori video seperti Beranda dan Trending.

---

##  Fitur Utama

-  Beranda (Home): Menampilkan daftar video rekomendasi dengan tata letak *grid* yang responsif.
-  Trending Page: Halaman khusus untuk menampilkan video yang sedang populer dan banyak ditonton.
-  Pencarian Video: Fitur pencarian untuk memfilter atau menemukan video berdasarkan kata kunci.
-  Antarmuka Responsif: Tampilan intuitif yang dapat menyesuaikan layar *desktop* maupun perangkat seluler.
-  Pemutar Video Interaktif: Fitur pemutaran video langsung di dalam web lengkap dengan kontrol *play/pause*.

---

##  Teknologi yang Digunakan

- **HTML5**: Struktur dan elemen halaman web.
- **CSS3 / Flexbox & Grid**: Penataan tata letak (*layout*), tata warna, dan efek animasi visual.
- **JavaScript (Vanilla)**: Logika interaktif, manipulasi DOM, dan navigasi antarmuka.
